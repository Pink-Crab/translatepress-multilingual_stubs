# TranslatePress - Multilingual Stubs

TranslatePress - Multilingual stubs for static analysis (PHPStan, Psalm, IDEs), generated by
[stub-forge](https://github.com/Pink-Crab/stub-forge) with
[php-stubs/generator](https://github.com/php-stubs/generator).
Includes private and protected members. Each git tag matches the plugin
version the stubs were generated from.

## Source

- Original plugin: <https://wordpress.org/plugins/translatepress-multilingual/>
- Plugin homepage: <https://translatepress.com/>

## Installation

```
composer require --dev pinkcrab/translatepress-multilingual_stubs:3.3.6
```
